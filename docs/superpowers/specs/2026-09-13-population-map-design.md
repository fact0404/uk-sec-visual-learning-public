# 階層型比例円・世界人口地図 設計仕様

- 文書状態: レビュー待ち
- 作成日: 2026-09-13
- 対象リポジトリ: `fact0404/uk-sec-visual-learning-public`
- 初期成果物: iPadおよびNotion埋め込みで利用できる自由探索型Webアプリ

## 1. 目的

世界人口を比例円で表し、地図を拡大すると大州、小地域、国、国内行政区画へ連続的に分割される教材を作る。

第一の目的は統計値の厳密な照合ではなく、次の関係を視覚的に理解できることである。

- 世界のどの地域に人口が多いか
- 一つの大きな人口が、どの国や地方へ分かれているか
- 上位地域の総量と下位地域の内訳がどのようにつながるか
- 地域間の人口規模がどの程度異なるか

将来は授業モードを追加するが、初期版は生徒が自由に移動・拡大できる探索モードに限定する。

## 2. 設計原則

優先順位は次のとおり。

1. 人口規模と内訳を直感的に理解できること
2. ズーム中の連続性と操作の滑らかさ
3. iPadとNotion埋め込みで迷わず操作できること
4. 人口以外の数量・比率へ拡張できること
5. 統計値と階層合計の厳密な一致

注釈は最小限とする。統計年、出典、推計区分は保持するが、通常画面には常時表示しない。

## 3. 対象範囲

### 3.1 初期版に含めるもの

- 独立したWebアプリ
- 同じWebアプリのNotion埋め込み
- iPad横向き全画面を基準とするレスポンシブ表示
- 世界から日本の市区町村までの意味的ズーム
- 人口を面積で示す比例円
- 親円から子円への連続分割
- 円の適応的な重なり回避
- 地域名と人口だけを示す簡潔な選択表示
- URLによる表示位置・ズーム状態の保持
- GitHub Pagesによる静的配信

### 3.2 初期版に含めないもの

- 年代スライダーと人口推移
- 教師用の授業進行モード
- 検索、ランキング、比較リスト
- GDP、人口密度などへの指標切替
- 比率を色で示す二変量表示
- ユーザーアカウント、学習履歴、分析
- 世界全体の第一行政区画
- APIサーバー、データベース、編集画面
- コロプレス、ドットマップ、フローマップ

これらは拡張用インターフェースだけを残し、実装しない。

## 4. 地理階層

基本階層は次のとおり。

```text
世界
└── 六大州
    └── 国連M49小地域
        └── 国・地域
            └── 第一行政区画
                └── 第二行政区画
```

初期版の国内階層は日本だけを対象とする。

- 第一行政区画: 都道府県
- 第二行政区画: 市区町村

将来の優先拡張対象はOECD加盟国、国連安全保障理事会常任理事国などの主要国とし、各国の第一行政区画を追加する。

各地理エンティティは集計用の親を一つだけ持つ。複数の大州にまたがる国や政治的扱いが分かれる地域も、集計上は一つの親へ割り当てる。国・地域名と小地域の基本対応には国連M49を使用し、六大州への対応だけ教材用の明示的な変換表を置く。

## 5. 意味的ズーム

### 5.1 地域ごとの詳細度

画面全体を一律に同じ階層へ切り替えない。各親地域が画面上で占める大きさから、その地域だけを分割する。

例:

- 世界表示では六大州の円
- 東アジアへ近づくと、アジアがM49小地域へ分割
- さらに東アジアへ近づくと、東アジアが国別へ分割
- 日本へ近づくと、日本が都道府県別へ分割
- 大阪府へ近づくと、大阪府が市区町村別へ分割
- 画面の端に残る遠方地域は、上位階層の円を維持

これにより、必要な地域だけが詳細化され、円の過密を避ける。

### 5.2 詳細度の判定

各地域の境界を画面座標へ投影し、画面に対する大きさを `detailScore` とする。階層ごとの設定値により分割開始・完了を決める。

- 分割開始しきい値: `splitStart`
- 分割完了しきい値: `splitEnd`
- 統合側には小さなヒステリシスを設け、境界付近の点滅を防ぐ
- しきい値は設定ファイルで調整し、コードへ固定しない

生のMapLibreズーム値だけでは、ロシアと日本のように国土面積が大きく異なる地域を同じ条件で扱えないため、画面上の地域寸法を主な判定値とする。

## 6. 比例円と連続分割

### 6.1 面積比例

人口値を (v)、基準係数を (k) とすると、半径は次式で求める。

```text
radius = k × sqrt(v)
```

人口が4倍なら面積が4倍、半径が2倍となる。

画面上の判読性を保つため、`radiusMinPixels` と `radiusMaxPixels` を設ける。同時表示中の円の相対的な面積比は維持する。

### 6.2 面積保存型の分割

分割進行率を (t = 0..1)、親人口を (V)、子人口を (v_i)、親円の基準半径を (R) とする。

```text
parentRadius(t) = R × sqrt(1 - t)
childRadius_i(t) = R × sqrt(t × v_i / V)
```

この計算により、分割途中でも親円と子円の合計面積を一定に保つ。

子円の位置は、親の代表点から子の代表点へ `t` に応じて線形補間する。不透明度だけのクロスフェードにはせず、位置と半径の両方を連続的に変える。

アニメーション時間で自動進行させず、利用者のズーム量を `t` に直接対応させる。途中で逆方向へズームした場合は、その位置から統合へ戻る。

### 6.3 統計年が異なる階層

表示する人口値には元データを使う。ただし、親と子の合計が一致しない場合は、分割描画に限り、子の人口比を保ったまま合計が親円に一致する描画値を作る。

```text
visualValue_i = parentValue × rawChildValue_i / sum(rawChildValues)
```

この補正は表示する人口数には使わない。統計上の厳密さより、分割中の連続性を優先するための描画処理である。

## 7. 円の配置と重なり回避

### 7.1 基本位置

円は行政機関の所在地ではなく、地域の形状から計算した視覚的中心へ置く。中心が地域外へ出やすい形状や島国には、手動のアンカー上書きを許可する。

### 7.2 適応型の重なり回避

通常は正しい代表点に置く。二つ以上の円が判読困難に重なる場合だけ、画面座標上で最小限ずらす。

- 大きい円を先に配置
- 小さい円を前面へ描画し、隠れにくくする
- 最大移動量を設定し、地域から大きく離さない
- 8pxを超えて移動した円には引出線を表示
- カメラ移動中は前回の配置を補間し、停止後に安定位置を再計算
- 計算結果は同じ表示状態に対して決定的にし、円が揺れ続けないようにする
- タップ時は対応する地域境界を強調する

円の見た目より広い透明なタップ領域を設け、小さな円にも最低44px相当の操作領域を確保する。

## 8. 表示と操作

### 8.1 通常画面

地図を最大限広く使い、常設要素を抑える。

- 左上: 現在の指標名「人口」
- 右側: 拡大、縮小、世界表示へ戻る
- 右上または埋め込み時: 「全画面で開く」
- 左下: 折りたたみ可能な比例円凡例
- 下部: 選択した地域の簡潔な情報カード

### 8.2 ラベル

- 六大州と小地域: 地域名と短縮人口を原則表示
- 国・行政区画: 衝突しない主要ラベルだけを表示
- 選択中の円: 地域名と人口を常に表示
- 小さい円: 通常時はラベルを省略し、タップで確認
- 短縮表示例: `14.4億人`、`875.7万人`
- 選択カード: 桁区切りした人口を表示
- 長い注釈、順位、割合、統計年、出典は初期状態で表示しない

### 8.3 ジェスチャー

- 一本指ドラッグ: 地図移動
- ピンチ: 拡大・縮小
- 円をタップ: 選択して地域名・人口を表示
- 地図の空白をタップ: 選択解除
- ダブルタップを必須操作にしない
- スクロールホイールとキーボード操作にも対応

### 8.4 URL状態

緯度、経度、ズーム、選択地域、指標IDをURLへ保存できるようにする。これにより将来、Notionから特定地域を開くリンクや授業用プリセットを作れる。

初期表示はURL指定がなければ世界全体とする。

## 9. 技術構成

### 9.1 採用技術

- TypeScript
- Vite
- MapLibre GL JS
- deck.gl
- Vitest
- Playwright
- GitHub Pages

MapLibreは地図投影、カメラ、ジェスチャー、地域境界の描画を担当する。deck.glは比例円、連続分割、タップ判定、引出線を担当する。

Reactは初期版では採用しない。常設UIが少なく、地図状態が中心であるため、TypeScriptの小さなモジュールとDOMで構成する。授業モードなど画面状態が大幅に増えた段階で再評価する。

### 9.2 背景地図

外部の地図タイルAPIへ依存しない。MapLibreに空の淡色スタイルを与え、必要な地域境界をリポジトリ内の簡略化GeoJSONから描画する。

理由:

- GitHub PagesでAPIキーを管理する必要がない
- Notion埋め込みで外部サービスの制約を受けにくい
- 道路や施設名を省き、人口円へ注意を集中できる
- 教材として必要な行政境界だけを段階的に読み込める

世界境界、都道府県境界、市区町村境界は階層別・親地域別に分割し、表示に必要なファイルだけ読み込む。

## 10. データモデル

### 10.1 地理エンティティ

```json
{
  "id": "jp-pref:27",
  "level": "admin1",
  "parentId": "iso3:JPN",
  "name": {
    "ja": "大阪府",
    "en": "Osaka"
  },
  "anchor": [135.52, 34.69],
  "boundaryRef": "jp-prefectures#27",
  "childrenData": "geography/jp-pref-27.json"
}
```

ID規則:

| 階層 | 例 |
|---|---|
| 世界 | `world` |
| 六大州 | `continent:asia` |
| M49小地域 | `unm49:030` |
| 国・地域 | `iso3:JPN` |
| 都道府県 | `jp-pref:27` |
| 市区町村 | `jp-muni:27217` |

### 10.2 観測値

```json
{
  "geoId": "jp-pref:27",
  "metricId": "population",
  "value": 8757000,
  "referenceDate": "2025-10-01",
  "sourceId": "jp-official",
  "valueStatus": "estimate"
}
```

### 10.3 指標定義

```json
{
  "id": "population",
  "label": {
    "ja": "人口",
    "en": "Population"
  },
  "unit": "people",
  "valueType": "total",
  "aggregation": "sum",
  "sizeChannel": "area",
  "colorChannel": null
}
```

将来、`valueType: rate`、`aggregation: weightedMean`、`colorChannel`を追加できる。ただし初期版の表示エンジンは人口の面積表現だけを有効にする。

## 12. データ出典方針

初期版では次を使用する。

- 世界、大州、小地域、国・地域の人口: [UN World Population Prospects](https://population.un.org/wpp/) の最新公開版から、アプリのデータ更新時点で利用できる最新年の推計
- 国・地域コードとM49小地域: [UN Statistics Division M49](https://unstats.un.org/unsd/methodology/m49/)
- 日本の都道府県人口: [総務省統計局 人口推計](https://www.stat.go.jp/data/jinsui/)
- 日本の市区町村人口: 総務省の住民基本台帳に基づく人口、人口動態及び世帯数調査の最新公開値
- 世界の国境形状: Natural Earthの簡略化データ
- 日本の行政境界: e-Stat統計GISの境界データ

取り込んだ元ファイル、取得URL、取得日、ライセンス、変換スクリプト、チェックサムをデータ生成領域に記録する。公開画面では注釈を抑えるが、再現性は失わない。

データ更新は初期版では手動実行とする。自動更新による形式変更や欠損の見逃しを避けるため、検証後に生成データをコミットする。

## 13. データ生成と検証

公開用JSONとGeoJSONは手作業で直接編集せず、変換スクリプトから生成する。

必須検証:

- IDが一意である
- `parentId`が存在する
- 循環参照がない
- 各ノードが世界まで到達する
- 人口値が有限の非負数である
- 同じ地理ID・指標・基準日の重複がない
- アンカーが有効な経緯度である
- 子データの収録率が設定値を満たす
- 生成ファイルのスキーマが正しい
- 出典と取得日が存在する

子地域の人口収録率が98%未満の場合、その親は自動分割しない。親円を残し、タップ時に「詳細データなし」と短く表示する。

## 14. 読み込みとキャッシュ

- 初期表示では世界境界、六大州、人口観測値、設定だけを読む
- 次階層の分割開始前に子データを先読みする
- 一度読んだデータはメモリへ保持する
- ブラウザキャッシュにはファイルハッシュ付きURLを使用する
- 読み込み中も親円を残し、空白状態を作らない
- 通信失敗時は一度だけ再試行する
- 再試行後も失敗した場合は親円を維持し、簡潔な再読込操作を表示する
- データ版が変わった場合だけ古いキャッシュを無効化する

Service Workerによる完全オフライン対応は初期版に含めない。

## 15. 障害時動作

| 状況 | 動作 |
|---|---|
| 子データ読込中 | 親円を維持し、分割開始を待つ |
| 子データ取得失敗 | 親円を維持し、小さな再読込表示 |
| 一部人口が欠損 | 収録率98%未満なら分割しない |
| 境界データ欠損 | 円は表示し、境界強調だけ省略 |
| WebGL初期化失敗 | 対応ブラウザで開く案内を表示 |
| URL状態が不正 | 不正部分を無視し、世界表示へ戻る |
| Notion埋め込みが狭い | 操作部を縮小し、全画面リンクを優先表示 |

技術的なエラー詳細を生徒向け画面へ表示しない。開発モードのコンソールには原因と対象ファイルを記録する。

## 16. アクセシビリティ

- 主要操作のタップ領域を44px以上にする
- 色だけで選択状態を示さず、輪郭とラベルを併用する
- 円と背景のコントラストを確保する
- キーボードで拡大、縮小、ホーム、選択解除を操作できる
- 選択カードをライブリージョンとして読み上げる
- `prefers-reduced-motion`では位置移動を抑え、短いフェード中心へ変更する
- 日本語UIを初期値とし、地理名データには英語名も保持する
- 地図だけでは理解できない利用者向けの一覧表示は将来拡張とする

## 17. 性能目標

対象は比較的新しいiPadのSafariと主要なデスクトップブラウザ。

- 初期表示用のアプリコードと初期データ: gzip後1MB以内を目標
- 初期地図表示: 通常の学校・家庭回線で3秒以内を目標
- ズーム・分割中: 60fpsを目標、継続的に30fpsを下回らない
- カメラ操作中に主スレッドを50ms以上占有する処理を避ける
- 衝突計算は表示中の円だけを対象とし、カメラ移動中は間引く
- 市区町村境界は都道府県単位で読み込む
- 画面外の子階層を描画しない

これらは受入試験時に実機またはSafari相当環境で計測し、端末差を記録する。

## 18. テスト方針

### 18.1 単体テスト

- 人口から半径への変換
- 面積保存式
- 親子の描画値補正
- 詳細度スコア
- 分割・統合のヒステリシス
- URL状態の解析と復元
- 日本語人口表記
- 衝突回避の最大移動量

面積保存は多数の無作為な親子人口でも誤差範囲内に収まることを検証する。

### 18.2 データ検証

第13節の検証をビルドとCIの両方で実行する。検証に失敗した生成データは公開しない。

### 18.3 結合・操作テスト

- 世界表示から東アジアの国別表示まで拡大できる
- 日本から都道府県、大阪府から市区町村へ連続分割できる
- 逆方向のズームで同じ経路を連続統合できる
- 円のタップで正しい地域名と人口が表示される
- 空白タップで選択が解除される
- URLを再読込して同じ表示へ戻る
- Notion相当の狭いiframeで主要操作を使える
- タッチ操作とマウス操作の双方が動く

### 18.4 視覚回帰テスト

世界、東アジア、日本、大阪府について、分割前・途中・完了の基準画像を保存する。円の消失、急な移動、ラベル衝突、境界の欠落を検出する。

## 19. 受入基準

初期版は、次をすべて満たしたとき完成とする。

1. 世界表示で六大州の人口円が表示される
2. 拡大した地域だけがM49小地域、国へ連続分割される
3. 日本が都道府県へ、大阪府を含む各都道府県が市区町村へ分割される
4. 分割中の親子円の総面積が許容誤差1%以内で保存される
5. 逆方向のズームで円が不連続に飛ばず統合される
6. 円の面積が同時表示内の人口比を正しく表す
7. 読めない重なりだけが回避され、移動量が上限内に収まる
8. 円をタップすると地域名と人口が表示される
9. データ取得失敗時に親円が消えない
10. iPad横向きとNotion埋め込みで地図操作を妨げる横スクロールがない
11. URLから表示状態を復元できる
12. 人口以外の指標を追加できる型とレジストリが存在するが、初期UIには表示されない
13. 自動テスト、データ検証、視覚回帰テストが成功する
14. 出典、取得日、データ版を公開データ内で追跡できる

## 21. 設計上の決定一覧

- 利用形態: 独立WebアプリとNotion埋め込みの両対応
- 初期モード: 自由探索
- 地理階層: 世界、六大州、M49小地域、国、日本の都道府県、市区町村
- 階層切替: 地域ごとの意味的ズーム
- 円の切替: ズーム量に連動した連続分割
- 面積: 人口比例、分割中も保存
- 大きさ: 最小・最大ピクセル半径で適応補正
- 重なり: 必要な場合だけ最小限回避
- 選択表示: 地域名と人口だけ
- 年代: 最新年のみ
- データ年: 世界・国は同一年、日本国内は最新の公式値
- 注釈: 通常画面では最小限
- 初期指標: 人口のみ
- 拡張設計: 円の面積に数量、色に比率
- 技術: TypeScript、Vite、MapLibre GL JS、deck.gl
- 配信: GitHub Pages、静的データ
- 背景: 外部タイルを使わず簡略化境界を自前配信
- データ更新: 検証付きの手動生成・コミット
